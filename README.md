# মুডসিঙ্ক (MoodSync) — Couples Mood App

> **“মুড লুকানোর জন্য নয়। মুড বোঝার জন্য। ❤️”**
>
> *“I can quickly tell my partner how I feel, and my partner can understand what is happening with me without needing to constantly ask.”*

**মুডসিঙ্ক (MoodSync)** একটি অতি-হালকা (ultra-lightweight), ব্যক্তিগত ও নিভৃত দুই-ব্যক্তির প্রোগ্রেসিভ ওয়েব অ্যাপ (PWA)। এটি দম্পতি বা যুগলদের জন্য তাদের তাৎক্ষণিক মনের অবস্থা, অনুভূতি ও প্রয়োজন পরস্পরের সাথে দ্রুত, সহজ ও সুন্দরভাবে ভাগ করে নেওয়ার জন্য তৈরি করা হয়েছে।

অ্যাপটি কোনো নজরদারি বা ট্র্যাকিং টুল নয়। এখানে উভয় সঙ্গীর অধিকার সমান এবং কোনো লুকানো অ্যাডমিন অ্যাক্সেস নেই।

---

## ✨ মূল বৈশিষ্ট্যসমূহ (Core Features)

1. **বাংলা-ফার্স্ট ইন্টারফেস ও নান্দনিক টাইপোগ্রাফি:**
   * প্রাকৃতিক কথোপকথনমূলক বাংলা ভাষা।
   * গুগল ফন্ট **`Hind Siliguri`** দিয়ে যেকোনো ডিভাইসে নিখুঁত যুক্তবর্ণ রেন্ডারিং।
2. **প্রশ্ন → উত্তর → পরবর্তী প্রশ্ন (Tactile Question Flow):**
   * **এখন কেমন লাগছে?** — ৮টি স্পষ্ট ইমোজি ও অর্থবহ বাংলা বিবরণ (😄 খুব ভালো, 🙂 ভালো, 😌 শান্ত, 😐 মোটামুটি, 😔 মন খারাপ, 😣 খুব খারাপ, 😡 রাগ লাগছে, 🥺 কষ্ট লাগছে)।
   * **এই মুহূর্তে তোমার কী দরকার?** — প্রয়োজন নির্বাচন (🫂 একটু আদর, 💬 কথা বলতে চাই, 👂 শুধু শুনো, 🧘 একটু space, 🤍 পাশে থাকো, 🤷 জানি না)।
   * **Closeness / Intimacy Mood** — ঐচ্ছিক ঘনিষ্ঠতার অনুভূতি।
   * **ছোট চিরকুট** — কোনো দীর্ঘ প্রশ্নমালা নয়, সম্পূর্ণ ঐচ্ছিক অনুভূতি নোট।
3. **“কিছু একটা হয়েছে” (Difficult Moment Quick Action):**
   * তর্ক বা মনস্তাত্ত্বিক জটিলতার মুহূর্তে কোনো দোষারোপ বা সম্পর্ক-স্কোরিং ছাড়া তাৎক্ষণিক অনুভূতি জানানো (রাগ, কষ্ট, অভিমান, চুপ থাকা ইত্যাদি)।
4. **রিয়েলটাইম সিনক্রোনাইজেশন (Supabase Realtime):**
   * এক সঙ্গী মুড আপডেট করার সাথে সাথে অন্য সঙ্গীর স্ক্রিনে মসৃণ ট্রানজিশনে আপডেট দৃশ্যমান হয় (সাব-সেকেন্ড লেটেন্সি)।
5. **মোবাইল স্লিপ/ওয়েক রেসিলিয়েন্স (Mobile Lifecycle Auto Re-sync):**
   * `visibilitychange` লিসেনার দিয়ে ফোন স্লিপ বা ব্যাকগ্রাউন্ড থেকে চালু হলে স্বয়ংক্রিয়ভাবে সর্বশেষ মুড সিঙ্ক করে।
6. **লাইটওয়েট ওয়েব পুশ নোটিফিকেশন (Web Push):**
   * ব্রাউজারের স্ট্যান্ডার্ড VAPID এবং সার্ভিস ওয়ার্কার দিয়ে কোনো থার্ড-পার্টি সার্ভিস ছাড়াই সঙ্গীর কাছে নোটিফিকেশন পৌঁছে যায়।
7. **সারাদিনের টাইমলাইন ও সাপ্তাহিক সারসংক্ষেপ:**
   * সারাদিনের মুড পরিবর্তনের ক্রমানুসারে দৃশ্যমান টাইমলাইন (অতীত তথ্য ওভাররাইট হয় না)।
   * গত ৭ দিনের অনুভূতির শান্ত ও নিরপেক্ষ সারসংক্ষেপ।
8. **জিরো থার্ড-পার্টি ট্র্যাকিং ও সর্বোচ্চ গোপনীয়তা:**
   * কোনো বিজ্ঞাপন নেই, কোনো গুগল অ্যানালিটিক্স নেই, কোনো সোশ্যাল নেটওয়ার্ক ট্র্যাকার নেই।
   * কৃত্রিম বুদ্ধিমত্তা (AI) দিয়ে কোনো মনস্তাত্ত্বিক ডায়াগনোসিস বা সিদ্ধান্ত চাপিয়ে দেওয়া হয় না।
9. **৩০ দিনের অটোমেটিক ডাটা রিটেনশন:**
   * গোপনীয়তা রক্ষার্থে ৩০ দিন বা নির্ধারিত সময় পর পুরনো টাইমলাইন স্বয়ংক্রিয়ভাবে মুছে যায়।
10. **ইনস্টলেবল PWA:**
    * মোবাইল ও ডেস্কটপে অ্যাপ হিসেবে ইনস্টলেবল (Home Screen Bookmark/Standalone mode)।
    * দ্রুত লোডিং এবং অফলাইন সমর্থন।

## 🛠 প্রযুক্তিগত কাঠামো (Tech Stack)

* **ফ্রন্টএন্ড:** [Next.js 16](https://nextjs.org) (App Router, React 19 canary, TypeScript)
* **স্টাইলিং:** [Tailwind CSS v4](https://tailwindcss.com) (ওয়ার্ম কালার প্যালেট, মোবাইল-ফার্স্ট)
* **আইকন:** [Lucide Icons](https://lucide.dev)
* **ফন্ট:** Google Font [`Hind Siliguri`](https://fonts.google.com/specimen/Hind+Siliguri)
* **ডাটাবেজ ও অথেনটিকেশন:** [Supabase Free Tier](https://supabase.com) (PostgreSQL, Supabase Auth, Supabase Realtime)
* **সিকিউরিটি:** PostgreSQL Row Level Security (RLS) পলিসি দিয়ে কাপল আইসোলেশন
* **পুশ নোটিফিকেশন:** Web Push API (`web-push`, Service Worker, VAPID)

## 🚀 লোকাল ডেভেলপমেন্ট সেটআপ (Local Setup)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ২. এনভায়রনমেন্ট ভেরিয়েবল কনফিগার করুন
`.env.example` ফাইল কপি করে `.env.local` তৈরি করুন:
```bash
cp .env.example .env.local
```

আপনার Supabase প্রজেক্ট থেকে পাওয়া তথ্য দিন:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

NEXT_PUBLIC_VAPID_PUBLIC_KEY=your-vapid-public-key
VAPID_PRIVATE_KEY=your-vapid-private-key
VAPID_SUBJECT=mailto:admin@yourdomain.com
CRON_SECRET=your-cron-secret
```

*(নতুন VAPID কী জেনারেট করতে চালান: `npx web-push generate-vapid-keys --json`)*

### ৩. ডাটাবেজ স্কিমা সেটআপ
Supabase ড্যাশবোর্ডের **SQL Editor**-এ গিয়ে [`supabase/schema.sql`](file:///mnt/01DAAF995C961E10/personal_projects/Fun%20Projects/moodsync/supabase/schema.sql) ফাইলটির কোড পেস্ট করে রান করুন।

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করুন।

## 🛡️ ডেটা ও প্রাইভেসি নিশ্চয়তা (Data & Privacy)

* **RLS (Row Level Security):** ডাটাবেজ স্তরে নিশ্চিত করা হয়েছে যে একজন ব্যক্তি শুধুমাত্র তার নিজ কাপলের ডাটা পড়তে ও লিখতে পারবে। অন্য কোনো কাপলের ডেটা অ্যাক্সেস অসম্ভব।
* **অনুমতিভিত্তিক অ্যাক্সেস:** অ্যাপ ডিভাইসের কোনো লোকেশন, ক্যামেরা, মাইক্রোফোন বা অন্যান্য অ্যাপ ব্যবহারের ট্র্যাকিং করে না।
* **উপাত্ত অধিকার:** সেটিংস থেকে যেকোনো সময় সকল ডাটা JSON আকারে ডাউনলোড (Export) করা যায় অথবা সমগ্র ইতিহাস মুছে ফেলা যায়।
